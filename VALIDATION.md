# Проверка сборки

Дата: 11 ноября 2026.

## Версия 1.1.0 — только аудио

- `testDebugUnitTest assembleDebug -PtargetAbi=arm64-v8a`: успешно. Восемь тестов пройдены (шесть новых для аудио и два существующих для ссылок).
- Проверены выбор аудиопотока и MP3-выхода, сохранение видеоформата, исключение незавершённых/промежуточных файлов из готовых загрузок, сериализация аудиозадачи и её состояния, чтение истории 1.0.0, независимые загрузки видео и аудио одной ссылки.
- Интеграционная проверка на хосте: скомпилированный `DownloadRequestFactory` создал настоящую команду загрузки, встроенный yt-dlp скачал локальный тестовый MP4 с видео и звуком, FFmpeg извлёк MP3. `ffprobe` подтвердил один аудиопоток MP3 и отсутствие видеопотока. Это проверяет команду и обработку звука, но не Android-среду или доступ к YouTube.
- APK: `versionCode=2`, `versionName=1.1.0`, ARM64, minSdk 26. Подпись проверена и совпадает с поставленной версией 1.0.0; допускается установка обновления поверх неё.
- Новая версия на физическом телефоне не проверялась. Полный цикл скачивания аудио именно с YouTube пока не подтверждён.

## Версия 1.0.0

- `testDebugUnitTest assembleDebug`: успешно, JDK 17, Gradle 8.13, Android SDK 35.
- Два JUnit-теста: допустимые варианты YouTube-ссылок, удаление tracking-параметров, отклонение поддельных доменов, некорректных ID и ссылок на плейлисты. Ошибок нет.
- APK подписан debug-ключом; подпись проверена `apksigner verify`. Включены ARM64, ARMv7 и x86_64.
- Дополнительно собран APK только для ARM64 командой `assembleDebug -PtargetAbi=arm64-v8a`. Размер — 73 829 999 байт. Подпись проверена, `aapt dump badging` подтверждает `arm64-v8a`, minSdk 26 / targetSdk 35. Этот APK доступен отдельно как `Pocketube-1.0.0-arm64.apk`.
- APK установлен на Android 9 / API 28 (x86_64, программная эмуляция). Проверены запуск, обе нижние вкладки, пустая видеотека и приём ссылки через `ACTION_SEND`. В этих сценариях аварийных завершений нет.
- После визуальной проверки исправлены цвета системных панелей и выбранных фильтров. Финальный APK успешно пересобран, тесты повторно прошли.

Полная цепочка получения метаданных YouTube → загрузка → остановка → продолжение → просмотр → удаление на устройстве **не подтверждена**. На медленном программном эмуляторе проверка остановилась на подготовке загрузчика/получении видео. Не следует считать проверку интерфейса доказательством скачивания. Перед повседневным использованием проверьте эту цепочку на физическом телефоне и доступном видео.

GitHub Actions сконфигурирован, но удалённый запуск пока не выполнен: создание репозитория текущим GitHub-подключением возвращает 403 `Resource not accessible by integration`. Исходники подготовлены в локальном Git-репозитории; push требует доступного удалённого репозитория.
