# Pocketube для Android

Приложение на русском языке для сохранения видео YouTube на телефон. Android 8.0+ (API 26), без аккаунта и отдельного сервера.

## Установка

Откройте поставляемый `Pocketube-1.0.0.apk` на телефоне и разрешите установку из выбранного источника. Это debug-сборка для личного использования; для публикации понадобится собственный release-ключ. После публикации проекта APK также можно получить из артефактов GitHub Actions.

## Как пользоваться

1. На нижней вкладке **Добавить** вставьте ссылку YouTube / youtu.be / Shorts и нажмите **Найти видео**. Также можно отправить ссылку из YouTube через **Поделиться → Pocketube**.
2. Проверьте название и обложку, выберите качество из доступных и нажмите **Скачать видео**.
3. На вкладке **Загрузки** видны очередь, прогресс, остановленные и готовые видео. Загрузки продолжаются при закрытии экрана приложения. Доступны остановка, продолжение, повтор после ошибки и удаление с подтверждением.
4. Готовое видео можно открыть в установленном видеоплеере или сохранить копию в выбранную папку через системный диалог.
5. Кнопка обновления вверху обновляет yt-dlp, если YouTube изменил способ выдачи видео. Перед обновлением остановите текущие загрузки.

## Хранение и ограничения

- Видео и частичные файлы хранятся в каталоге приложения `Android/data/com.pocketube.app/files/Movies/Pocketube/`. Если внешнее хранилище недоступно, используется внутреннее. Данные сохраняются при перезапуске приложения. Кэш загрузчика и обложек находится в кэше приложения.
- Повторное добавление одного видео в том же качестве не создаёт копию. После остановки yt-dlp использует сохранённые фрагменты, когда формат и источник это позволяют; если источник изменился, часть загрузки может начаться заново.
- Удаление в приложении удаляет его локальные файлы и фрагменты. Копии, сохранённые через системный диалог, остаются у пользователя. Удаление самого приложения удаляет его хранилище.
- До двух загрузок одновременно. Остальные ждут слот. Для старта нужны сеть и достаточно свободного места. Android может ограничивать долгие фоновые задачи, особенно при энергосбережении и после принудительной остановки приложения. Кнопка «Продолжить» запускает сохранённую задачу снова.
- Контейнер предпочтительно MP4; для некоторых форматов возможен MKV/WebM. Разрешение в карточке — выбранный верхний предел: если такой вариант недоступен, выбирается доступный ниже.
- Доступность зависит от YouTube, сети и региона. Закрытые, платные, DRM-защищённые и требующие входа видео не поддерживаются. Приложение не импортирует cookies аккаунта. Прямая ссылка на трансляцию принимается; завершённые записи обрабатываются как обычное видео.
- Сохраняйте видео, на которые у вас есть права или разрешение автора.

## Сборка

Требуются JDK 17+, Android SDK 35 / Build Tools 35.0.0. Gradle Wrapper включён.

```bash
git clone https://github.com/Vanchegs/pocketube-android.git
cd pocketube-android
# Укажите sdk.dir в local.properties или задайте ANDROID_HOME.
./gradlew testDebugUnitTest assembleDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`. В APK включены ARM64, ARMv7 и x86_64. Нативные Python / FFmpeg увеличивают размер APK.

Чтобы получить APK меньшего размера для современных телефонов ARM64:

```bash
./gradlew assembleDebug -PtargetAbi=arm64-v8a
```

Отдельная сборка `Pocketube-1.0.0-arm64.apk` устанавливается на устройства с ABI `arm64-v8a`.

GitHub Actions выполняет тесты и сборку при push в `main`; APK доступен в артефактах запуска.

## Устройство проекта

- Kotlin + Jetpack Compose / Material 3 — интерфейс с двумя нижними вкладками.
- WorkManager + foreground-уведомления — устойчивые фоновые задачи и управление процессами.
- `DownloadRepository` — атомарное JSON-хранилище истории, файлов и идентификаторов задач. Идентификатор запуска защищает состояние от запоздалых обновлений отменённой задачи.
- youtubedl-android (yt-dlp + Python + QuickJS) и FFmpeg — получение информации, загрузка и объединение потоков на самом телефоне.
- Coil — обложки и их дисковый кэш; FileProvider — безопасное открытие видео; Storage Access Framework — экспорт без разрешения на весь диск.

Учётные данные GitHub, файлы видео, SDK и локальные ключи подписи не входят в репозиторий. Аналитики и своего сервера нет; получение видео обращается к YouTube, обновление загрузчика — к GitHub.
