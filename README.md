# Pocketube для Android

Приложение на русском языке для сохранения видео YouTube и их аудиодорожек на телефон. Android 8.0+ (API 26), без аккаунта и отдельного сервера.

## Установка

Откройте поставляемый `Pocketube-1.3.0-arm64.apk` на телефоне ARM64 и разрешите установку из выбранного источника. Это debug-сборка для личного использования; для публикации понадобится собственный release-ключ. Версию 1.3.0 можно установить поверх предыдущих сборок с той же подписью, сохранив историю и файлы. После публикации проекта APK также можно получить из артефактов GitHub Actions.

## Как пользоваться

1. На нижней вкладке **Добавить** вставьте ссылку YouTube / youtu.be / Shorts и нажмите **Найти видео**. Также можно отправить ссылку из YouTube через **Поделиться → Pocketube**.
2. Выберите **Видео** или **Только аудио**. Для видео доступны варианты разрешения и кнопка **Скачать видео**. Для аудио — **Скачать аудио**: выбирается лучший доступный аудиопоток, FFmpeg сохраняет его в MP3. Если отдельного аудиопотока нет, звук извлекается из доступного объединённого потока. MP3-конвертация не повышает качество исходной записи.
3. На вкладке **Загрузки** видны очередь, прогресс, остановленные и готовые файлы с отметкой «Аудио · MP3» или разрешением видео. Загрузки продолжаются при закрытии экрана приложения. Доступны остановка, продолжение, повтор после ошибки и удаление с подтверждением. Одна ссылка может быть сохранена отдельно как видео и как аудио.
4. Готовое видео открывается кнопкой **Смотреть**, аудио — кнопкой **Слушать** во встроенном плеере. Копию файла можно сохранить в выбранную папку через системный диалог. Аудио экспортируется как `audio/mpeg` с расширением `.mp3`.
5. Кнопка обновления вверху проверяет официальный релиз yt-dlp и показывает установленную версию. Перед ручным обновлением остановите текущие загрузки. После установки обновления у ранее неудачной загрузки нажмите **Повторить**.

## Встроенный плеер

- После начала воспроизведения над нижними вкладками появляется мини-плеер. Для видео он показывает настоящий видеокадр. Пауза и закрытие доступны прямо на мини-панели; нажатие на название разворачивает плеер.
- Полный экран содержит перемотку, переходы на 10 секунд, предыдущий и следующий файл. Сворачивание сохраняет позицию. Для аудио показаны обложка, название и плавно переливающийся градиент.
- Кнопка разворота в правом нижнем углу видео включает горизонтальный полноэкранный режим со скрытыми системными панелями. Касание кадра показывает или скрывает управление; при воспроизведении оно исчезает через 3,5 секунды. Кнопка выхода или «Назад» возвращает обычный плеер с прежней позицией. Интерфейс учитывает поворот устройства. В горизонтальной ориентации видео автоматически занимает весь экран; при возврате в портретную возвращается обычная компоновка. Ручной полный экран также поворачивается вместе с устройством. Выход из горизонтального плеера сворачивает его в мини-панель.
- Под плеером есть шкала громкости 0–200% и кнопки ±10%. До 100% регулируется громкость приложения, выше — усиление до +6 дБ через Android LoudnessEnhancer. Системная громкость телефона задаётся отдельно. Усиление может давать искажения; если аудиоэффект недоступен на устройстве, шкала ограничена 100% с пояснением. В горизонтальном режиме регулятор открывается кнопкой динамика.
- Переходы вкладок и плеера, появление мини-панели, перестановка и удаление карточек анимируются средствами Compose. Учитывается системная длительность анимаций. Иконка Android адаптивная: зелёный фон заполняет всю маску лаунчера.
- Воспроизведение выполняет Media3 ExoPlayer в `PlaybackService` с медиасессией: аудио продолжает играть при сворачивании и блокировке экрана, управление доступно в системном уведомлении. Отключение наушников приостанавливает воспроизведение. Принудительная остановка приложения завершает плеер.
- Очередь формируется из скачанных файлов текущей подборки в выбранном порядке. Выбор того же файла из другого плейлиста обновляет очередь и сохраняет позицию. Плеер работает с локальными файлами медиатеки.

## Плейлисты

На вкладке **Загрузки** нажмите **+** рядом с надписью **Плейлисты**, чтобы создать подборку. Кнопка с плейлистом в карточке скачанного файла позволяет включить его в одну или несколько подборок, снять отметку или создать новую. Кнопка **Готово** сохраняет изменения.

Горизонтальный ряд переключает всю медиатеку, файлы без плейлиста и конкретную подборку. В меню сортировки доступны порядок добавления и сортировка по названию, а для выбранного плейлиста — переименование и удаление. Удаление плейлиста сохраняет медиафайлы. Удаление самого файла также убирает его из плейлистов и очереди плеера.

Плейлисты хранятся атомарно в `files/playlists.json`, сохраняются после перезапуска приложения и обновления APK.

## Обновление загрузчика

В APK включён официальный yt-dlp **2026.10.26** вместе с EJS-скриптами для JavaScript-проверок YouTube. Android-библиотека 0.18.1 сама содержит старый yt-dlp 2025.11.12, поэтому приложение устанавливает проверенный архив из своих assets до инициализации библиотеки. Существующая старая копия заменяется, более новая версия сохраняется.

В 1.1.2 исправлена проверка версии на новых Android: официальный Unix zipapp начинается со строки запуска Python, которую строгий `ZipFile` не принимает как ZIP-заголовок. Для чтения версии используется `ZipInputStream` с начала ZIP-содержимого. Байты исходного файла и проверка SHA-256 сохраняются.

При получении метаданных или начале загрузки проверяется официальный стабильный релиз, не чаще раза в сутки. Проверка обновления недоступна офлайн — в этом случае используется архив из APK. Скачанные обновления проверяются по SHA-256 и версии, затем атомарно заменяют рабочий файл. Установка не происходит во время чтения загрузчика другой активной задачей. При HTTP 403/410 или ошибке извлечения подписи выполняются принудительная проверка обновления, очистка кэша загрузчика и максимум одна новая попытка с получением свежих ссылок.

Ошибка 403 может быть вызвана и ограничениями YouTube для конкретного видео или сети; актуальный загрузчик не гарантирует доступ к любому ролику. Компоненты и инструкция настройки JavaScript: https://github.com/yt-dlp/yt-dlp/wiki/EJS.

## Хранение и ограничения

- Видео и частичные файлы хранятся в каталоге приложения `Android/data/com.pocketube.app/files/Movies/Pocketube/`. Если внешнее хранилище недоступно, используется внутреннее. Данные сохраняются при перезапуске приложения. Кэш загрузчика и обложек находится в кэше приложения.
- Повторное добавление видео в том же качестве или аудио той же ссылки не создаёт копию. После остановки yt-dlp использует сохранённые фрагменты, когда формат и источник это позволяют; если источник изменился, часть загрузки может начаться заново. Тип загрузки сохраняется после перезапуска и продолжения.
- Удаление в приложении удаляет его локальные файлы и фрагменты. Копии, сохранённые через системный диалог, остаются у пользователя. Удаление самого приложения удаляет его хранилище.
- До двух загрузок одновременно. Остальные ждут слот. Для старта нужны сеть и достаточно свободного места. Android может ограничивать долгие фоновые задачи, особенно при энергосбережении и после принудительной остановки приложения. Кнопка «Продолжить» запускает сохранённую задачу снова.
- Контейнер предпочтительно MP4; для некоторых форматов возможен MKV/WebM. Разрешение в карточке — выбранный верхний предел: если такой вариант недоступен, выбирается доступный ниже.
- Доступность зависит от YouTube, сети и региона. Закрытые, платные, DRM-защищённые и требующие входа видео не поддерживаются. Приложение не импортирует cookies аккаунта. Прямая ссылка на трансляцию принимается; завершённые записи обрабатываются как обычное видео.
- Сохраняйте видео, на которые у вас есть права или разрешение автора.

## Сборка

Требуются JDK 17+, Android SDK 35 / Build Tools 35.0.0. Gradle Wrapper включён.

```bash
cd pocketube-android
# Укажите sdk.dir в local.properties или задайте ANDROID_HOME.
./gradlew testDebugUnitTest assembleDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`. В APK включены ARM64, ARMv7 и x86_64. Нативные Python / FFmpeg увеличивают размер APK.

Чтобы получить APK меньшего размера для современных телефонов ARM64:

```bash
./gradlew assembleDebug -PtargetAbi=arm64-v8a
```

Отдельная сборка `Pocketube-1.3.0-arm64.apk` устанавливается на устройства с ABI `arm64-v8a`.

GitHub Actions выполняет тесты и сборку при push в `main`; APK доступен в артефактах запуска.

## Устройство проекта

- Kotlin + Jetpack Compose / Material 3 — интерфейс с двумя нижними вкладками.
- WorkManager + foreground-уведомления — устойчивые фоновые задачи и управление процессами.
- Media3 ExoPlayer / MediaSessionService — встроенное видео и аудио, мини-плеер и фоновое воспроизведение.
- `PlaylistRepository` — атомарное хранение подборок, состава и названий.
- `DownloadRepository` — атомарное JSON-хранилище истории, файлов и идентификаторов задач. Идентификатор запуска защищает состояние от запоздалых обновлений отменённой задачи.
- youtubedl-android (yt-dlp + Python + QuickJS) и FFmpeg — получение информации, загрузка и объединение потоков на самом телефоне.
- Coil — обложки и их дисковый кэш; Storage Access Framework — экспорт без разрешения на весь диск.

Учётные данные GitHub, файлы видео, SDK и локальные ключи подписи не входят в репозиторий. Аналитики и своего сервера нет; получение видео обращается к YouTube, обновление загрузчика — к GitHub.
